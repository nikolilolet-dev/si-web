# Aplicacion web

This contains everything you need to run your app locally.

La aplicacion se publica automaticamente en GitHub Pages desde la rama `main`.

## Run Locally

**Requisitos:** Node.js


1. Instala las dependencias:
   `npm install`
2. Ejecuta la aplicacion:
   `npm run dev`
